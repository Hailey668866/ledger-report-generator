# macOS 图片导出目录选择修复设计

日期：2026-08-14
状态：用户已确认

## 问题

“导出图片”当前调用 `QFileDialog.getExistingDirectory`。在 macOS 上该静态接口使用原生 `NSOpenPanel`，界面和确认按钮表现为“打开”，用户无法明确判断这是保存目录选择，而不是打开文件。

## 设计

使用应用内的非原生 `QFileDialog` 替换静态目录接口：

- 文件模式固定为 `Directory`，只接受文件夹。
- 启用 `ShowDirsOnly`，不允许选择普通文件。
- 启用 `DontUseNativeDialog`，保证 macOS 与 Intel/Apple 芯片版本行为一致。
- 确认按钮显示“选择此文件夹”，取消按钮显示“取消”。
- 取消或未返回目录时不调用 PNG 导出器。
- 选择目录后仍在其中生成“经营汇总.png”和“自营项目周报.png”，不改变图片内容与命名。

## 范围

本轮不修改 Excel 缩放、报表计算、PNG 渲染、导入流程或其他平台行为。

## 验收

- 自动化测试验证目录模式、仅目录选项、非原生选项和确认按钮文案。
- 自动化测试验证取消不导出、选中目录后将该目录传给 `export_pngs`。
- 全量测试、Ruff 和 Git 差异检查通过。
