# C 版桌面界面还原设计

日期：2026-08-13
状态：用户已确认

## 目标

把当前 PySide6 主窗口还原为用户此前确认的 C 版收起式预览界面，并修复验收截图中的中文字体发虚、变形问题。业务计算、导入格式、历史记录、Excel/PNG 导出和卸载行为保持不变。

## 视觉基准

以 `.superpowers/brainstorm/visual-20260808-145609-1333/content/layout-c-v3-collapsed-preview.html` 为唯一视觉基准：

- 顶部品牌栏显示用户提供的应用图标、应用名和数据源就绪状态。
- 主体使用白色紧凑面板、绿色主色、克制阴影和 5-8px 圆角。
- 两个数据源各占一行，包含短标识、名称、文件名和“选择文件”按钮。
- 数据校验后显示两块周期信息：经营汇总的财年/截止日期，以及自营项目的最新完整 Week。
- “生成两张报表”是整行绿色主按钮。
- 生成后在底部结果操作区启用“预览报表”“导出 Excel”“导出图片”。预览仍通过弹窗按标签切换两张表。

## 状态文字边界

- 删除当前主界面独立的 `已生成：W1（8.1-8.6）` 状态条。
- 不长期展示“报表已生成 + Week”的状态文案。
- 保留生成前的周期核对信息，因为它用于确认本次处理范围。
- 后台任务进行中可以临时显示“正在校验数据源…”或“正在生成报表…”。成功后恢复为简短就绪状态，不在主界面重复 Week。

## 字体与图标

- 继续使用用户最初提供、当前资源目录中的 `app-icon.png`，不重新生成或替换。
- 打包内置一份开源简体中文无衬线字体，应用启动时优先注册并使用该字体；注册失败时才回退到 macOS/Windows 中文系统字体。
- 内置字体必须随 PyInstaller 资源进入 macOS `.app`，主窗口与预览弹窗使用同一字体族。

## 功能边界

保持：

- 两份 XLSX 的选择与拖放。
- 数据源校验和生成前范围确认。
- 后台线程执行及忙碌状态。
- 收起式预览弹窗。
- Excel 和两张 PNG 导出。
- 应用菜单内一键卸载。

不新增联网、账号、自动上传或业务规则变化。

## 验收

- UI 自动测试覆盖品牌图标、C 版布局层级、周期信息、结果操作区和 Week 状态条移除。
- 字体测试覆盖内置字体资源、注册优先级和打包资源。
- 全量测试、Ruff、格式和 Git diff 检查通过。
- 使用实际 PySide6 程序生成主窗口和预览弹窗截图；截图中文字清晰、无重叠、无裁切，并与 C 版原型一致。
- 用户确认截图后，再提交并构建新的 arm64/x86_64 macOS DMG。
