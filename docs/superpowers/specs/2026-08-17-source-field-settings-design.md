# 数据源字段设置设计

日期：2026-08-17
状态：用户已确认

## 目标

允许用户在不修改程序的情况下，应对资金台账和运营台账的工作表名称、表头所在行及关键字段名称变化。列顺序和无关列仍不受限制。

## 方案选择

采用“默认值加文本输入”方案：程序列出所有关键参数，用户只把发生变化的名称改成新值。

未采用：

- 自动猜测相似字段。字段含义判断错误会直接影响金额和利润结果。
- 每次导入后重新映射。重复操作多，不适合固定模板的每周更新。

## 界面

主窗口数据源区域增加“字段设置”按钮，打开一个简洁的设置窗口。窗口分为“资金台账”和“运营台账”两个标签页，每项只显示名称和输入框，不增加字段说明。

资金台账默认项：

- 工作表名称：`资金散板汇总{年份}`
- 表头行：`1`
- 渠道名称：`渠道名称`
- 付款日期：`信容付款日期`
- 付款金额：`付款金额合计（90%）`
- 应收操作费：`应收操作费`

运营台账默认项：

- 工作表名称：`台账明细`
- 表头行：`1`
- 提单号：`提单号`
- 项目类型：`项目类型`
- 目的口岸：`目的口岸`
- 预计起飞时间：`预计起飞时间`
- B1 供应商：`B1供应商`
- 预估总应收：`预估总应收`
- 预估毛利润：`预估毛利润`

底部提供“恢复默认”“取消”“保存”三个操作。保存后关闭窗口，并在已选择两份数据源时立即重新校验。

## 工作表名称规则

资金台账名称中的 `{年份}` 由程序替换为所需自然年。例如默认设置会读取“资金散板汇总2026”和“资金散板汇总2027”。如果输入值不含 `{年份}`，则按用户填写的完整工作表名称读取一个工作表。

运营台账按用户填写的完整工作表名称读取。

## 读取规则

- 程序从用户设置的表头行读取表头，并按设置中的字段名称定位数据列。
- 字段可左右移动，也可插入无关列；数据必须继续位于相应表头下方。
- 字段名称按输入框内容精确匹配，不自动猜测近似名称。
- 所有名称必须非空；同一张表内的关键字段名称不能重复；表头行必须是正整数。
- 找不到工作表或字段时，错误信息明确显示设置项和当前填写的名称。
- 未保存过设置时使用现有默认值，保证已有用户升级后行为不变。

## 保存与卸载

设置以 JSON 文件保存在现有应用数据目录中，使用标准库进行读取和原子写入。设置只保存在本机，不上传网络。

一键卸载已经删除整个应用数据目录，因此字段设置也会随应用一起删除，无需新增卸载路径。

## 验收

- 自定义运营工作表名称、资金工作表名称及年份占位符后可正确读取。
- 自定义表头行和所有关键字段名称后可正确读取。
- 列顺序变化、前置空列和额外无关列不影响读取。
- 空名称、重复字段名称和非法表头行不能保存。
- 设置可跨应用重启保留，“恢复默认”可还原全部默认值。
- 保存设置后会重新校验已选择的数据源。
- 原始三份样例在默认设置下结果保持不变。
- 全量测试、Ruff、格式和 Git 差异检查通过。
