# 台账报表生成器 macOS 安装说明

本应用已经包含所需运行环境，无需安装 Python，也无需联网。

## 安装

1. 根据 Mac 芯片下载对应文件：Apple 芯片（M1/M2/M3/M4 等）使用 `arm64`，Intel 芯片使用 `x86_64`。
2. 双击下载的 `.dmg` 文件并打开 DMG。
3. 将“台账报表生成器”拖到“Applications（应用程序）”文件夹。
4. 安装后可以推出 DMG，并从 Finder 的“应用程序”打开应用。

## 首次打开

当前版本未签名、未经过 Apple 公证，首次双击时 macOS 可能提示无法验证开发者。这不表示需要安装 Python。

请在 Finder 的“应用程序”中找到“台账报表生成器”，右键应用图标，选择“打开”，再在确认窗口中选择“打开”。后续可正常双击启动。

若右键后仍被阻止，请打开“系统设置” > “隐私与安全性”，在安全提示处确认打开该应用。只应对从项目发布页取得的安装包执行此操作。

## 固定到 Dock

应用运行时，右键 Dock 中的应用图标，选择“选项” > “在程序坞中保留”。macOS 通常不需要桌面快捷方式；之后可从 Dock、启动台或“应用程序”打开。

## 卸载

在应用菜单中选择“卸载台账报表生成器…”，确认后会删除程序本身以及应用内部数据、缓存、偏好设置、日志和临时数据。

卸载不会删除用户自行选择位置中已经导出的 Excel 或 PNG 文件。如需删除这些导出文件，请在 Finder 中手动处理。
